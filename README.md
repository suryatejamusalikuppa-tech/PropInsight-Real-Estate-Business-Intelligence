## 📌 Project Overview

PropInsight is a real estate business intelligence project focused on analyzing UAE property market data using SQL.

The project involves organizing, validating, and analyzing data related to property listings, agencies, agents, locations, and transactions to generate meaningful business insights.

The main objective is to transform raw data into reliable business information that supports KPI reporting, market analysis, and data-driven decision-making.

## 🎯 Project Objectives

- Design and understand a relational database.
- Import and validate CSV datasets using MySQL Workbench.
- Analyze real estate listings across UAE locations.
- Calculate key performance indicators (KPIs).
- Identify the most frequently listed property types.
- Analyze agency and agent listing activity.
- Evaluate completed property transactions.
- Identify data-quality issues.
- Generate actionable business insights and recommendations.

## 📂 Dataset Overview

The project uses six related datasets:

| Dataset | Description |
|---|---|
| Locations | UAE cities, emirates, and residential communities |
| Agencies | Real estate agencies and business details |
| Agents | Agents associated with real estate agencies |
| Properties | Property types, bedrooms, bathrooms, area, and furnishing status |
| Listings | Property sale and rental listings, asking prices, and listing status |
| Transactions | Transaction dates, values, and transaction outcomes |

## 📊 Business Analysis

### 1. Property Listing Analysis
- Identify communities with the highest number of listings.
- Compare sale listings with rental listings.
- Analyze property listing distribution across UAE locations.

### 2. Asking Price Analysis
- Calculate average asking prices for properties for sale.
- Calculate average annual rental asking prices.
- Compare asking-price patterns across property types and locations.

**Note:** Sale prices and annual rental prices are analyzed separately because they represent different business measures.

### 3. Agency and Agent Analysis
- Identify agencies managing the highest number of listings.
- Rank agents according to listing activity.
- Compare listing distribution across agencies.

### 4. Transaction Analysis
- Count successfully completed transactions.
- Calculate the total value of completed transactions.
- Analyze completed transaction values across relevant categories.

**Important:** Only transactions marked `COMPLETED` are included in completed-transaction KPIs. Transaction value is not the same as agency commission or company revenue.

### 5. Data Quality Analysis
- Identify missing and NULL values.
- Detect duplicate records.
- Check invalid prices, dates, and property details.
- Identify inconsistent labels and categories.
- Detect orphan references between related tables.
